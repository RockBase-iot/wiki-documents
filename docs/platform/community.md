## Latest Announcements

### K230 AI Development Board — Coming Soon

The next-generation **K230 AI development board** has been announced with:

- **CanMV** support
- **Large model** support
- **6 TOPS** equivalent compute
- **1 GB / 2 GB** runtime memory

The product page for its module form, [K230-Vision](../products/k230-vision.md), is already live; this page will be updated when the board officially launches.

### Web Flasher Is Live

[flash.rockbaseiot.com](https://flash.rockbaseiot.com) is now available for browser-based ESP32 flashing, covering popular community projects such as Bruce, Marauder, and ESP-Claw. See the [Web Flasher Guide](./web-flasher.md).

:::
