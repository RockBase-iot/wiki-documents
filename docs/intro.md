# RockBase IoT Wiki

Welcome to the **RockBase IoT** Developer Documentation Center.

## Quick Start

RockBase IoT focuses on providing high-quality IoT hardware and solutions for developers and makers. This documentation covers product specifications, development guides, project cases, and more.

## Documentation Structure

| Section | Content |
|---------|---------|
| **Products** | Hardware product specifications and quick start guides |
| **Developer** | Development guides, API references, firmware flashing |
| **Projects** | Open-source projects and case tutorials |
| **Applications** | Typical application scenarios and deployment solutions |

## Core Products

- **NM-CYD-C5** — ESP32-C5 Core Development Board (Wi-Fi 6 + Zigbee + Thread)
- **NM-RF-HAT** — RF Expansion Module (CC1101 / nRF24 / PN532 / IR)
- **NM-Display-2.8** — 2.8" Touch Display (ESP32-S3 + IMU + RTC + Audio)
- **NM-EPD-420** — 4.2" E-Paper Display tri-color or B/W (ESP32-S3 + LoRa + Audio)
- **NM-TV-154** — 1.54" Desktop Mini TV (ESP32 + ST7789 + Touch Key)
- **NM-Solar** — Solar UPS Power Supply Board for Low-Power IoT Nodes
- **K230-Vision** — AI Vision Module (6 TOPS / CanMV / Multimodal AI)
