# Hardware Buddy Desktop Companion

The Hardware Buddy series explores "AI assistant + physical hardware" interaction: small desktop devices become a physical extension of your AI. This page covers the two companion projects.

## Buddy Bridge App

Repository: [RockBase-iot/buddy-bridge-app](https://github.com/RockBase-iot/buddy-bridge-app) (created 2026-06-18)

Buddy Bridge App is a **local desktop companion** for Hardware Buddy devices — targeting models that do not use BLE and communicate over **USB serial** only, bridging data between your computer and the device.

## Claude Desktop Buddy

Repository: [RockBase-iot/claude-desktop-buddy](https://github.com/RockBase-iot/claude-desktop-buddy) (created 2026-06-22)

Claude Desktop Buddy is a **reference and example project for the Claude Cowork / Bluetooth API** aimed at makers, demonstrating how a hardware device can work with the Claude desktop app over the Bluetooth API — for example, mirroring AI conversation states, notifications, or expressions onto a small desktop device in real time.

## Related Projects

- [DeskBuddy-TV](./deskbuddy-tv.md) — desktop weather/expression companion firmware for the NM-TV-154, sharing the same "desktop AI companion" product thinking
- [pizero-openclaw](https://github.com/RockBase-iot/pizero-openclaw) — OpenClaw-related experiments on Pi Zero (created 2026-07-10)

:::info Product Line
Hardware Buddy is RockBase IoT's emerging desktop-interaction product line: device-side firmware (e.g. DeskBuddy-TV) + bridge software (Buddy Bridge App) + AI integration examples (Claude Desktop Buddy). Together they form an approachable path into "AI + IoT desktop terminal" scenarios.
:::
