# ESP32-Weather-EPD 墨水屏气象站

**ESP32-Weather-EPD** 是经典的低功耗墨水屏气象站项目：ESP32 定时唤醒，从 OpenWeatherMap API 拉取天气数据，板载传感器提供室内温湿度，刷新完成后回到深度睡眠。RockBase 分支已适配 [NM-EPD-420](../products/nm-epd-420.md)。

- 固件仓库：[RockBase-iot/esp32-weather-epd](https://github.com/RockBase-iot/esp32-weather-epd)
- 数据API：OpenWeatherMap（需自行申请免费 API Key）

## 双面板支持

| 面板 | 分辨率 | 特点 |
|------|--------|------|
| 7.5" 经典面板 | 800×480 | 高分辨率，信息量大 |
| 4.2" 三色面板 | 400×300 | **成本显著更低**，经重新优化的 UI 布局保留了同样丰富的天气信息与相近的视觉体验 |

## 功耗与续航

- 睡眠电流约 **14 µA**
- 刷新期间约 83 mA（7.5" 约 15 秒，4.2" 三色约 10 秒）
- 5000 mAh 电池、30 分钟更新频率下，续航 **6–12 个月**
- USB-C 充电，带电量监测

## 显示与定制

- 逐小时预报图：温度折线 + 降水概率（可选降水量）阴影柱状图
- 多语言、多单位、多种时间/日期格式、多种 AQI 标准
- 丰富的个性化配置选项

## 硬件清单（参考）

| 部件 | 推荐型号 | 备注 |
|------|----------|------|
| ESP32 | FireBeetle 2 ESP32-E | 低功耗设计、USB-C、电池管理 |
| 墨水屏 | 见仓库 Panel Support 章节 | 7.5" 或 4.2" 三色 |
| 转接板 | DESPI-C02 | 不推荐 Waveshare HAT（rev 2.2/2.3） |
| 传感器 | BME280 | 温度、湿度、气压，3.3V/5V 兼容 |
| 电池 | 3.7V LiPo（JST-PH2.0） | 5000 mAh 可运行 6 个月以上 |

:::tip 免焊接方案
直接使用 NM-EPD-420 开发板可省去转接板与焊接：板载 4.2" 三色/黑白墨水屏、AHT20 温湿度传感器、电池管理与 USB-C，仓库已提供适配分支与 NM-EPD-420 实机演示图。
:::
