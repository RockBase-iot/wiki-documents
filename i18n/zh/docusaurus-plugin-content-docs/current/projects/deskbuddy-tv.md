# DeskBuddy-TV 桌面天气伴侣

**DeskBuddy-TV** 是专为 [NM-TV-154](../products/nm-tv-154.md) 打造的桌面天气 / 表情小摆件固件。它将 1.54 英寸小方屏变成一个会眨眼、会卖萌的桌面伙伴，同时提供完整的天气与空气质量信息。

- 固件仓库：[RockBase-iot/deskbuddy-tv](https://github.com/RockBase-iot/deskbuddy-tv)
- 适用硬件：NM-TV-154（ESP32 + ST7789 240×240 + 电容触摸键）

## 页面功能

设备共 6 个页面，按顺序循环切换：

| 页面 | 内容 |
|------|------|
| 1. 表情眼睛 | 会眨眼、会转动眼珠的动画眼睛，支持 7 种表情 |
| 2. 时钟 | 当前时间、日期与设备 IP 地址 |
| 3. 实时天气 | 温度、天气状况、体感温度、湿度、风速、气压 |
| 4. 五日预报 | 日期、最高/最低温、降雨概率与天气状况 |
| 5. 逐小时曲线 | 24 小时温度折线图 + 降雨概率柱状图 |
| 6. 空气质量 | 美标/欧标 AQI、PM2.5、PM10、O₃、NO₂、CO |

## 表情系统

在「表情眼睛」页面**长按触摸键**可循环切换表情：

1. **普通** — 经典椭圆眼睛 + 圆形瞳孔
2. **圆圆眼** — 全圆形眼睛
3. **爱心眼** — 心形瞳孔
4. **星星眼** — 星形瞳孔
5. **生气** — 皱眉表情
6. **卖萌** — 高椭圆眼睛 + 腮红 + 小嘴巴
7. **眼镜** — 戴眼镜的微笑表情

## 触摸交互

| 手势 | 功能 |
|------|------|
| 单击触摸键 | 切换页面 |
| 长按触摸键 | 在眼睛页面切换表情 |

触摸键为板载电容触摸（T9 / GPIO32），无需外接任何按键。

## 快速上手

1. 通过 [Web Flasher](https://flash.rockbaseiot.com) 或 PlatformIO 烧录固件
2. 首次启动后按屏幕提示完成 Wi-Fi 配网与城市设置
3. 配网成功后设备自动获取天气数据，单击触摸键即可浏览各页面

:::info 开发参考
如果你想基于 NM-TV-154 开发自己的固件，建议先阅读官方 PlatformIO Demo 工程（[NM-TV-154 仓库](https://github.com/RockBase-iot/NM-TV-154)），其中包含显示驱动、触摸检测与背光 PWM 调光的完整最小实现。
